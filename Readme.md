
## Implemented (p5): top-down RPG
Open [`leaky-pipe.html`](leaky-pipe.html) (serve the folder for best results). Scripts: [`rpg-world.js`](rpg-world.js) (map, collision, tiles, camera, random pipe breaks), [`rpg-player.js`](rpg-player.js) (player, input, **E** to patch a **broken pipe** tile you face), [`top-down-rpg.js`](top-down-rpg.js) (p5 `setup`/`draw`, HUD, timer). Tile types: grass (walk), wall, green pipe (blocked), broken pipe (blocked until patched back to pipe).
